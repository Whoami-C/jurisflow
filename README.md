# JurisFlow

CRM jurídico construído a partir do plano de estágio em Engenharia de Dados.

Inclui oportunidades, clientes, processos, prazos e tarefas em kanban, importação CSV com pré-visualização, busca, autenticação, persistência relacional, validações e auditoria.

## Desenvolvimento

- `npm run dev`: inicia o ambiente local.
- `npm run check`: executa lint, testes e build.
- `npm run db:generate`: gera uma nova migration após mudanças em `db/schema.ts`.

Consulte `docs/data-dictionary.md` e `docs/runbook.md` antes de alterar dados ou publicar.
